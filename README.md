# ⚔️ League of Legends: Perks & Champions Guide Companion

[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Web-brightgreen.svg)]()
[![License](https://img.shields.io/badge/License-MIT-gold.svg)](LICENSE)
[![LoL Version](https://img.shields.io/badge/LoL%20Data-v16.19.1%20RU-red.svg)]()

> Интерактивная энциклопедия и настольное ПК-приложение (.EXE) для League of Legends: подробные гайды по всем 173 чемпионам, веткам рун (перкам), оптимальным сборкам предметов и рекомендациям для **новичков** и **опытных игроков (ветеранов)**.

---

## 🌟 Возможности проекта

- 🎮 **Все 173 чемпиона:** актуальные характеристики, распределение по линиям (*Top, Mid, Jungle, Bot, Support*), описания способностей и рекомендуемые сборки.
- 🔮 **Полная система перков и рун:** все 5 великих ветвей (*Точность*, *Доминирование*, *Колдовство*, *Храбрость*, *Вдохновение*) с интерактивными тултипами, точными цифрами урона, исцеления и перезарядок.
- 🌱 **Советы новичкам:** подборка простых чемпионов (*Гарен, Энни, Эш, Мальфит, Люкс, Мастер Йи*) с понятной механикой, прощающих ошибки.
- 🔥 **Для опытных игроков:** персонажи с высоким потолком навыка (*High Skill-Cap: Ривен, Зед, Ясуо, Ли Син, Катарина, Афелий*) и продвинутые тактики роуминга.
- 💻 **Автономное приложение для ПК (.EXE):** готовый исполняемый файл размером ~650 КБ, не требующий установки дополнительных библиотек.
- 🌐 **Web-версия:** адаптивный интерфейс в стиле клиента LoL (Hextech / Dark Gold), оптимизированный под любые экраны.

---

## 🚀 Как пользоваться

### 1. Скачать готовое приложение для ПК (.EXE)
Перейдите в папку [`bin/`](bin/) и скачайте файл **`LoL_Perks_App.exe`**.  
Запустите его двойным кликом — приложение готово к работе!

### 2. Онлайн-сайт (GitHub Pages)
Веб-версия руководства доступна онлайн:
👉 **[Открыть League of Legends Guide Online](https://warfaiser.github.io/lol-perks-companion/)**
